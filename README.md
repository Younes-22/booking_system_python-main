Developed a booking system to book rooms during the provided times.

Each user must enter their name
Each user must enter a university email twice to ensure theu wrote it correctly
Users can select a date and time slot which is available to book a room for 45 minutes.
Once the user clicks submit a confirmation page appears with the details of their confirmation
The database is updated to include the new booking 
A confirmation email is sent to the user with the details of their booking
